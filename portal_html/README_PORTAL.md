# 計算物理学ドキュメントポータル 閲覧ガイド

このフォルダには、Quartoを用いてビルドされた以下のドキュメントが含まれています。

1. **Rust計算物理学チュートリアル (Web Book版)**: `book/index.html`
2. **イジング模型 転移温度解析メモ (HTML版)**: `Memo.html`

別のパソコンにこのデータを移動して閲覧するための手順を以下にまとめます。

---

## 1. 移動・コピーするファイル

別のパソコンで閲覧するには、以下の **1つのフォルダ** と **1つのファイル** をセットでコピーします。

* `portal_html/` フォルダ（このガイドやHTMLデータ本体が含まれるフォルダ）
* `run_portal.bat` ファイル（ワンクリックでローカルサーバーを起動するためのスクリプト）

---

## 2. 閲覧方法

### 方法A：Webサーバー経由で閲覧する（推奨）
数式（LaTeX）やレイアウトを崩さずに、検索機能などを含めて完璧に表示するための最も確実な方法です。

1. コピーしたフォルダ内の **`run_portal.bat`** をダブルクリックして実行します。
2. コマンドプロンプト（黒い画面）が立ち上がり、自動で簡易Webサーバーが起動します。
3. ブラウザで以下のURLにアクセスします。
   * **[http://localhost:8080](http://localhost:8080)**
4. 終了するときは、コマンドプロンプトの画面を閉じるか、画面上で `Ctrl+C` を押してください。

> **動作要件**: 起動するパソコンに **Python (3.x以降)** または **Node.js** がインストールされている必要があります。

---

### 方法B：ファイルを直接開く（簡易方法）
Python などの開発環境がない場合の最もシンプルな閲覧方法です。

1. **`portal_html/index.html`** をダブルクリックしてブラウザで開きます。
2. ポータル画面から各ドキュメントへアクセスできます。

> **注意**: ブラウザのローカルファイルに対するセキュリティ制限（CORS制限）により、一部の数式表示（MathJax/KaTeX）やリンクの挙動が制限される場合があります。その場合は以下の「環境がない場合の代替手段」をお試しください。

---

## 3. サーバーが動かない（Python等がない）場合の代替手段

移動先のパソコンに Python も Node.js も入っていない環境で、かつ「方法B」で数式などが正しく表示されない場合は、以下の方法で簡易サーバーを立ち上げることができます。

1. **VS Code の拡張機能を利用する**:
   * VS Codeで `portal_html` フォルダを開き、拡張機能 **「Live Server」** をインストールして起動します。
2. **ブラウザの拡張機能を利用する**:
   * Google Chrome の拡張機能 **「Web Server for Chrome」** などの簡易サーバーアプリをブラウザにインストールし、`portal_html` フォルダを指定して起動します。
